# Simple Voting Smart Contract

This project demonstrates the deployment of a Simple Voting Smart Contract on SecureChain (SCAI) Mainnet using Solidity, Remix IDE, and MetaMask wallet.

## Technologies Used

- Solidity
- Remix IDE
- MetaMask
- SecureChain Mainnet (SCAI)

## Features

- Vote for Candidate 1
- Vote for Candidate 2
- View total votes
- Blockchain-based voting logic

## Deployment Process

1. Installed MetaMask wallet
2. Added SecureChain Mainnet network
3. Received SCAI faucet tokens
4. Created Simple Voting smart contract in Remix IDE
5. Compiled Solidity contract
6. Connected MetaMask with Remix
7. Deployed contract successfully on SecureChain Mainnet

## Outcome

Successfully deployed the Simple Voting Smart Contract on SecureChain Mainnet using Solidity, Remix IDE, and MetaMask wallet.
